# 💼 Kerenizza - Personal Portfolio Website

---

## 📌 Description

Kerenizza is a fully responsive personal portfolio website designed to showcase my education, experience, and skills as an Information Technology student.  
This project serves as an online resume and portfolio that highlights my background, technical abilities, and web development practice.

The goal is to present a clean, modern, and professional personal website that is accessible on all devices.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Responsive Web Design
